# product-video

从用户提供的产品、受众、功能和场景出发，先做事实表与素材表。缺图且 Agent 可联网时，从产品官网核对型号、外观和事实，再找能解释功能的实拍素材；保存 URL、作者、许可、实际使用段落。不能联网就明确缺什么，不编造搜索结果。素材候选交用户挑选后再制作。

每镜用“这个功能让用户做了什么”解释画面选择。实拍、后期裁切、动画示意分别标明；不能把裁切说成真实相机焦段测评。产品图尺寸和镜头布局以参照为准。

`examples/index.tsx` 的 ProductDemo 只演示代码动效和导出方法。Agent 在任务目录据需求写自己的 Remotion 场景，不把这个测试模板当正式成片。先做 8–10 秒带声预览，检查产品外观、字幕、场景与功能是否对得上，再延长。图像/视频生成需使用读者已有工具；包里没有服务凭据，也不保证一次生成达到广告片质量。
